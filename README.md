# CareFlow — Clinical Pathway Process Mining

## Project Overview
CareFlow is a healthcare process analytics project that studies patient journeys in a hospital emergency department using timestamped event data.

## Problem Statement
Delays and repeated activities in patient journeys can increase the time required to complete hospital visits. This project aims to analyze patient event logs and identify potential bottlenecks.

## Objectives
- Generate a synthetic patient event dataset.
- Analyze patient activity sequences and waiting times.
- Discover and visualize patient pathways.
- Identify repeated activities and potential bottlenecks.
- Develop a dashboard to present key findings.

## Technology Stack
- Python
- Pandas
- PM4Py
- Matplotlib
- Power BI
- GitHub

## Project Status
Initial setup — dataset generation and process analysis are planned next.

## Data Privacy
The prototype will use synthetic data, not identifiable patient records.
