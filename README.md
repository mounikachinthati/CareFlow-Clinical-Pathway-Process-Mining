# 🏥 CareFlow: Clinical Pathway Process Mining

## Project Overview
CareFlow is an interactive data analytics dashboard designed to visualize and analyze clinical pathways, patient flows, and hospital operational efficiency. This project serves as the front-end UI for tracking patient journeys and operational metrics.

## Features
- **Executive Dashboard:** High-level KPIs including Total Patients, Avg. Length of Stay, Readmission Rate, and Patient Satisfaction.
- **Process Mining & Patient Flow:** Visualizes bottlenecks in the clinical pathway (Admission ➡ Diagnosis ➡ Treatment ➡ Discharge) and analyzes pathway variations.
- **Synthetic Dataset:** Includes a generated dataset of 500+ patient records for testing and demonstration.

## Tech Stack
- **Language:** Python
- **Framework:** Streamlit (for the UI)
- **Data Processing:** Pandas
- **Visualization:** Custom HTML/CSS & Plotly
